# 实验结果

> 此目录用于存放实验结果截图与图表。

## 已生成

- 📊 `training_curves.png` — 训练 loss 曲线（运行 `run_demo.py` 后生成）
- 📈 `predictions_vs_actual.png` — 测试集预测 vs 真实
- 💰 `backtest_equity_curve.png` — 回测资金曲线

## 如何生成

```bash
python run_demo.py
```

运行后会在此目录生成 `*.png` 图表。

## 临时占位

> 在此插入图表前，先把图片保存为 `assets/training_curves.png` 等文件名，
> 然后在 README 的「实验结果」部分用 `![](assets/training_curves.png)` 引用。
